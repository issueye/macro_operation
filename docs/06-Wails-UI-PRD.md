# Wails UI 产品需求文档

## 1. 产品概述

### 1.1 背景
目前系统仅提供命令行界面，用户体验较差。为了提升用户体验，增加可视化操作界面，决定引入Wails框架构建桌面GUI应用。

### 1.2 目标
构建一个现代化、直观的桌面界面，支持所有现有命令行功能，并提供更好的用户体验。

### 1.3 技术选型
- 后端: Go 1.21+ + Wails v3
- 前端: Vue 3 + Vite + TailwindCSS

## 2. 功能需求

### 2.1 核心功能
1. **宏录制功能**
   - 开始录制按钮
   - 停止录制按钮
   - 录制状态实时显示
   - 录制事件数量统计

2. **宏管理功能**
   - 宏列表展示
   - 保存录制的宏
   - 播放宏
   - 删除宏
   - 查看宏脚本内容

3. **一键操作**
   - 录制并保存功能（一键完成录制和保存）

### 2.2 辅助功能
1. **设置界面**
   - 宏存储目录配置
   - 播放速度配置

2. **状态反馈**
   - 所有操作的成功/失败提示
   - 实时操作日志显示

### 3.2 界面风格
- 简洁现代的设计风格
- 清晰的视觉层次和操作引导
- 响应式布局，适应不同屏幕尺寸
- 统一的配色方案和交互模式

## 4. 技术实现

### 4.1 后端实现
1. 使用Wails v3构建Go后端
2. 封装现有service层为Wails RPC方法
3. 实现前端与后端的通信
4. 处理录制状态的实时通知

### 4.2 前端实现
1. 使用Vue 3 + Vite构建单页面应用
2. 使用TailwindCSS实现样式
3. 实现与后端的RPC调用
4. 实现实时状态更新和操作反馈

## 5. 交互流程

### 5.1 录制流程
1. 点击"开始录制"按钮
2. 系统开始捕获键盘鼠标事件
3. 界面显示录制状态和事件数量
4. 点击"停止录制"按钮结束录制
5. 录制的宏可以保存或直接播放

### 5.2 播放流程
1. 从宏列表中选择一个宏
2. 点击"播放"按钮
3. 系统执行宏操作
4. 界面显示播放状态和结果
