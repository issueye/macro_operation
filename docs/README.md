## 项目概述

### 产品定位

**操作宏录制和回放**是一款桌面自动化工具,通过录制用户的键盘和鼠标操作,生成可重复执行的JavaScript脚本,帮助用户自动化处理重复性操作任务。

### 核心价值

1. **提升效率**: 将重复性操作自动化,节省80%以上的人工时间
2. **降低错误**: 避免人工重复操作中的失误
3. **易于使用**: 简单录制即可生成自动化脚本,学习成本低
4. **灵活扩展**: 基于JavaScript,支持高级用户自定义逻辑

### 目标用户

- **主要用户**: 办公室职员、数据录入人员、测试人员
- **次要用户**: 开发者、高级用户

### 技术栈

- **语言**: Go 1.21+
- **键盘监听**: gohook
- **鼠标监听**: robotgo
- **脚本引擎**: goja (JavaScript)
- **UI框架**: Fyne

## 技术架构

### 整体架构

```
┌─────────────────────────────────────────┐
│           用户界面层 (UI)                │
│         Fyne GUI Framework              │
└─────────────────────────────────────────┘
                  ↕
┌─────────────────────────────────────────┐
│         业务逻辑层 (Service)             │
│  RecordService │ PlayService │ MacroSvc │
└─────────────────────────────────────────┘
                  ↕
┌─────────────────────────────────────────┐
│         核心引擎层 (Engine)              │
│  Recorder │ Generator │ Executor        │
└─────────────────────────────────────────┘
                  ↕
┌─────────────────────────────────────────┐
│         基础设施层 (Infrastructure)      │
│  gohook │ robotgo │ goja │ Storage      │
└─────────────────────────────────────────┘
```

### 核心模块

#### 1. 事件捕获模块
- **职责**: 实时捕获键盘和鼠标事件
- **技术**: gohook + robotgo
- **性能要求**: 延迟 < 50ms

#### 2. 脚本生成模块
- **职责**: 将事件序列转换为JavaScript代码
- **技术**: 代码生成器 + 模板引擎
- **质量要求**: 代码可读性强,格式规范

#### 3. 脚本执行模块
- **职责**: 执行JavaScript脚本
- **技术**: goja引擎 + API绑定
- **安全要求**: 沙箱执行,权限控制

#### 4. 宏管理模块
- **职责**: 宏的存储和管理
- **技术**: JSON文件存储
- **功能**: CRUD操作、导入导出

#### 5. 用户界面模块
- **职责**: 提供用户交互界面
- **技术**: Fyne框架
- **要求**: 简洁美观,操作直观
