# 操作宏录制和回放 - 产品需求分析

## 一、产品概述

### 1.1 产品定位
操作宏录制和回放工具是一款自动化办公辅助工具，通过记录用户的键盘和鼠标操作序列，并将其保存为可重复执行的宏脚本，帮助用户自动化处理重复性操作任务。

### 1.2 核心价值
- **提升效率**: 将重复性操作自动化，节省人工操作时间
- **降低错误**: 避免人工重复操作中的失误
- **易于使用**: 简单录制即可生成自动化脚本
- **灵活扩展**: 支持JavaScript脚本，允许高级用户自定义逻辑

### 1.3 目标用户
- **主要用户**: 办公室职员、数据录入人员、测试人员
- **次要用户**: 开发者、高级用户（需要自定义脚本逻辑）

## 二、用户场景分析

### 2.1 核心使用场景

#### 场景1: 数据批量处理
**用户痛点**:
- 每天需要从Excel复制数据到网页表单
- 重复性的数据录入工作耗时且容易出错

**使用流程**:
1. 用户打开宏录制工具
2. 点击"开始录制"
3. 执行一次完整的数据录入操作（选择Excel单元格→复制→切换到网页→粘贴→点击提交）
4. 点击"停止录制"
5. 保存为"数据录入"宏
6. 下次处理新数据时，只需播放该宏

**预期收益**:
- 将每次5分钟的操作缩短到10秒
- 准确率从95%提升到100%

#### 场景2: 软件测试自动化
**用户痛点**:
- 测试人员需要反复执行相同的测试步骤
- 回归测试工作量大

**使用流程**:
1. 录制一次完整的测试操作序列
2. 保存为测试用例宏
3. 每次代码更新后自动播放宏进行回归测试

**预期收益**:
- 测试效率提升80%
- 测试覆盖率提高

#### 场景3: 批量文件操作
**用户痛点**:
- 需要对大量文件执行相同的操作
- 手动操作繁琐且易出错

**使用流程**:
1. 录制单个文件的完整操作流程
2. 修改生成的JS脚本添加循环逻辑
3. 批量处理所有文件

### 2.2 用户旅程地图

```
发现需求 → 打开工具 → 开始录制 → 执行操作 → 停止录制
    ↓
保存宏 → 命名管理 → 执行回放 → 验证结果 → 优化调整
```

### 2.3 用户需求层次

| 需求层次 | 需求内容 | 优先级 |
|---------|---------|--------|
| 基础需求 | 录制鼠标键盘操作、保存为宏、回放执行 | P0 |
| 期望需求 | 宏管理、编辑功能、快捷键支持 | P1 |
| 兴奋需求 | 智能识别、云端同步、宏市场 | P2 |

## 三、功能需求分析

### 3.1 核心功能模块

#### 模块1: 操作录制模块
**功能描述**: 实时捕获并记录用户的键盘和鼠标操作

**详细需求**:
- 支持键盘事件捕获（按键按下、释放）
- 支持鼠标事件捕获（点击、移动、滚动、拖拽）
- 支持屏幕截图记录（可选）
- 实时显示录制状态
- 支持暂停/继续录制
- 记录操作时间戳

**验收标准**:
- 能够准确捕获所有键盘和鼠标操作
- 录制过程不影响正常操作
- 录制延迟小于50ms

#### 模块2: 宏生成模块
**功能描述**: 将录制的操作序列转换为可执行的JavaScript脚本

**详细需求**:
- 自动生成JavaScript代码
- 代码结构清晰、可读性好
- 包含必要的注释
- 支持代码压缩和格式化
- 提供API封装文档

**验收标准**:
- 生成的代码语法正确
- 代码可读性强
- 支持手动编辑

#### 模块3: 宏管理模块
**功能描述**: 对已保存的宏进行组织和管理

**详细需求**:
- 保存/加载宏文件
- 宏列表展示
- 宏重命名
- 宏删除
- 宏分类（文件夹管理）
- 宏搜索功能
- 宏导入/导出

**验收标准**:
- 支持至少100个宏管理
- 搜索响应时间小于500ms
- 支持JSON格式的宏文件

#### 模块4: 回放执行模块
**功能描述**: 执行保存的宏脚本

**详细需求**:
- 支持单次执行
- 支持循环执行（指定次数）
- 支持定时执行
- 支持快捷键触发
- 实时显示执行状态
- 支持暂停/停止执行
- 执行速度调节（0.5x - 2x）
- 执行日志记录

**验收标准**:
- 执行准确率99%以上
- 支持长时间运行（24小时+）
- 异常情况自动停止

#### 模块5: 脚本编辑模块
**功能描述**: 允许高级用户编辑和优化生成的脚本

**详细需求**:
- 内置代码编辑器
- 语法高亮
- 代码提示
- 错误检查
- 调试功能
- API文档查询

**验收标准**:
- 编辑器响应流畅
- 语法提示准确

#### 模块6: 用户界面模块
**功能描述**: 提供友好的用户交互界面

**详细需求**:
- 主窗口（控制面板）
- 录制状态指示器
- 宏列表视图
- 脚本编辑器窗口
- 设置面板
- 托盘图标
- 快捷键设置

**验收标准**:
- 界面简洁美观
- 操作直观易懂
- 响应速度快

## 四、非功能需求

### 4.1 性能要求
- 录制响应时间: < 50ms
- 脚本生成时间: < 1s
- 内存占用: < 100MB (空闲状态)
- CPU占用: < 5% (空闲状态)
- 支持录制时长: 无限制

### 4.2 可靠性要求
- 系统稳定性: 7×24小时运行不崩溃
- 执行准确率: > 99%
- 异常恢复: 自动保存未保存的宏
- 数据完整性: 宏文件不丢失、不损坏

### 4.3 安全性要求
- 权限控制: 需要用户授权才能录制
- 数据加密: 敏感操作可加密保存
- 沙箱执行: 脚本在受限环境中执行

### 4.4 兼容性要求
- 操作系统: Windows 10/11 (优先), macOS, Linux
- 分辨率: 支持1920×1080及以上
- 多显示器: 支持双显示器

### 4.5 可用性要求
- 学习成本: 新用户5分钟内学会使用
- 操作步骤: 录制和回放不超过3步
- 错误提示: 清晰明了的提示信息

### 8.3 关键技术点

#### 1. 事件捕获
```go
// 使用gohook监听键盘
func startKeyboardHook() {
    evChan := hook.Start()
    for ev := range evChan {
        if ev.Kind == hook.KeyDown {
            handleKeyDown(ev)
        }
    }
}

// 使用robotgo监听鼠标
func startMouseHook() {
    mEvent := robotgo.AddEvents("mouse", 10)
    for {
        mouseEvent := <-mEvent
        handleMouseEvent(mouseEvent)
    }
}
```

#### 2. 脚本生成
```go
func generateScript(operations []Operation) string {
    var builder strings.Builder

    builder.WriteString("// Auto-generated macro script\n")
    builder.WriteString("function main() {\n")

    for i, op := range operations {
        builder.WriteString(fmt.Sprintf("  %s\n", op.ToJavaScript()))
    }

    builder.WriteString("}\n")
    return builder.String()
}
```

#### 3. 脚本执行
```go
func executeScript(script string) error {
    vm := goja.New()

    // 注册API
    registry := NewAPIRegistry()
    registry.RegisterAll(vm)

    // 执行脚本
    _, err := vm.RunString(script)
    return err
}
```
