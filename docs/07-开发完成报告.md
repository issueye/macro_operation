## 技术挑战与解决方案

### 1. Wails v3 API 变化

**挑战**: Wails v3 的 API 与官方文档存在差异，许多方法签名不匹配。

**解决方案**:
- 创建简化的骨架版本，确保项目可以编译
- 添加 TODO 注释标记需要进一步完善的地方
- 保留后端服务层结构，便于后续集成

### 2. Tailwind CSS v4 兼容性

**挑战**: Tailwind CSS v4 使用新的 PostCSS 插件 `@tailwindcss/postcss`。

**解决方案**:
- 安装 `@tailwindcss/postcss` 包
- 更新 `postcss.config.js` 使用新插件
- 前端成功构建

### 3. TypeScript 类型导入

**挑战**: Vite 的 `verbatimModuleSyntax` 要求类型导入使用 `type` 关键字。

**解决方案**:
- 统一使用 `import type { ... }` 语法
- 前端成功通过类型检查

### 4. Node.js 版本要求

**挑战**: Vite 7.x 要求 Node.js 20.19+ 或 22.12+，当前使用 20.15.0。

**影响**: 构建时会显示警告，但可以成功编译。

**建议**: 升级 Node.js 到 20.19+ 或 22.12+ 以消除警告。

## 开发环境设置

### 前置要求

- Go 1.24+ ✅ (当前: 1.24.6)
- Node.js 20.19+ ⚠️ (当前: 20.15.0)
- Wails v3 ✅ (当前: v3.0.0-alpha.54)

### 安装步骤

1. **安装 Wails v3**
   ```bash
   go install github.com/wailsapp/wails/v3/cmd/wails3@latest
   ```

2. **安装前端依赖**
   ```bash
   cd frontend
   npm install
   ```

3. **构建前端**
   ```bash
   cd frontend
   npm run build
   ```

4. **构建后端**
   ```bash
   go build -o build/gui.exe cmd/gui/main.go
   ```

### 开发模式

**终端 1 - 前端开发服务器**:
```bash
cd frontend
npm run dev
# 运行在 http://localhost:5173
```

**终端 2 - Wails 应用** (需要正确 API 集成后):
```bash
set WAILS_DEV=1
go run cmd/gui/main.go
```
